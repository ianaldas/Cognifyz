## 📌 About the Project

This repository contains all tasks completed during my **Web Development Internship** at **Cognifyz Technologies**.

The internship is structured into **3 progressive levels**, designed to strengthen core front-end development skills including HTML, CSS, JavaScript, and responsive frameworks.

---

## 🎯 Internship Objectives

* Build strong fundamentals in **HTML5 & CSS3**
* Improve interactivity using **JavaScript (Vanilla JS)**
* Learn responsive design using **media queries**
* Work with frameworks like **Bootstrap & Bulma**
* Develop real-world mini frontend projects
